# Tanakh — s teqbaylit (selah-kab)

Da ara d-tafeḍ Tira taɛbranit (Tanakh) s teqbaylit. Yal taseddart tesɛa afaylu-ines,
yal awal n teqbaylit yeqqim **zdat n wawal-ines n taɛbranit** — yiwen n yizirig awal
s wawal, d yiwet n tefyirt i tɣuri.

Taqbaylit tettwaru da s yisekkilen ilatiniyen n Tmaziɣt. Isekkilen **`ɛ ɣ ḥ ṭ ẓ č ǧ`**
(akked `ḍ ṛ ṣ`) d isekkilen n tidet, mačči d acebbaḥ: `ɣ` mačči d `gh`, `ɛ` mačči d
`â`. **Ulac isekkilen n tefransist** (`é è ê à`) deg wawalen n teqbaylit; ma tufiḍ-ten,
d tuccḍa. Ulac isekkilen n taɛrabt, ulac Tifinaɣ — d alatini kan.

> **Aḍris-agi yura-t umsatal, yettraju ameẓẓuɣ n teqbaylit.**
> Anda ur telli ara taqbaylit d tasaḥit, neɣ tewɛer, neɣ ur tesɛi ara ṣṣut n umdan
> i yettmeslayen — **ilaq ad tettwaṣeggem.** Taɛbranit tella ɣer tama n yal awal,
> ihi tzemreḍ ad twaliḍ s yiman-ik.

> **Aḍris-agi yettwasenqad tura.** Kra n wawalen n teglizit kecmen ɣer daxel n
> tecciwin `⟨…⟩`, u kra n tseddarin ur msaḍant ara d wawalen n taɛbranit. Tiseddarin-agi
> ttwakksent, ttwasuqulent tikkelt nniḍen. Ma tufiḍ taseddart ur nelli ara, d tin
> yettrajun.

Maca **ɣer `CONTRIBUTING.md` uqbel ad tṣeggmeḍ kra.** Kra n wayen i yettbanen d
tuccḍiwin d afran s lebɣi, yettwasegzen dinna.

---

## Amek ara teɣreḍ taseddart

Yal taseddart tesɛa sin n wudmawen, u **ilaq ad ɣreḍ SIN-NSEN:**

- **awalen** — yiwen n wawal n teqbaylit i yal awal n taɛbranit, akken d-ttasen deg
  taɛbranit;
- **tafyirt** — taseddart am tefyirt n teqbaylit.

Si yiwet n tseddart n taɛbranit i d-ttekken i sin. **Ma ur msaḍan ara, d ayen ilaqen
ad d-yettwammel.**

Amedya, Tazwara 1:1 (`genesis/1/1`):

> Deg tazwara, Elohim yexleq ⟨את⟩ igenwan d ⟨את⟩ tmurt.

## Ticraḍ

| tacraḍt | anamek-is |
|---|---|
| `⟨awal⟩` | awal **ur nelli ara** deg taɛbranit — yettwarna akken ad tili teqbaylit |
| `⟨את⟩` | tazelɣa n taɛbranit i yesbeggnen asemmad usrid. **Ulac awal n teqbaylit i t-yettaken.** Mačči d tuccḍa n tira |

`⟨את⟩` yeqqim deg wemkan-is axaṭer taɛbranit tesbeggin asemmad usrid, taqbaylit ur
t-tesbeggin ara. Mi ara yeqqim yettban, ameɣri yettwali **anda yella** — ur nettmeslay
ara am akken yella yenger. Tilɣiwin-is (am `⟨אתו⟩`) qqiment akken diɣen.

## Isem

**`Yahwe`** d Isem, yettwaru s timesliwin n teqbaylit. **Mačči `Ṛebbi`, mačči `Sidi`,
mačči `Allah`.** *Ṛebbi* d awal yelhan n teqbaylit — maca mačči d Isem. Anda tenna
taɛbranit `יהוה`, Isem yeqqim. Usmekti 6:4 (`deuteronomy/6/4`):

> Yisrael, cecleḍ: Yahwe Elohim-nneɣ, Yahwe d yiwen.

Ismawen nniḍen n taɛbranit qqimen akken llan: **Elohim** · **El** · **Eloha** ·
**Adonai** · **Caddai** · **Yahwe Ṣebaot**. Ma yella ubab d amdan, d **bab** neɣ
**sidi** s yisekkil amecṭuḥ — d ameɣtu. Ma d iṛebbiten n leǧnas d tugniwin, d
**ṛebbi** / **iṛebbiten** s yisekkil amecṭuḥ.

Isefra 23:1 (`psalms/23/1`):

> Mizmor n David: Yahwe d amɣar-iw n wulli, ur xuṣṣeɣ ara.

## Awalen yeqqimen s taɛbranit

Mačči akk awalen i yettwasuqlen. Kra deg-sen qqimen s talɣa n taɛbranit axaṭer ulac
awal n teqbaylit ara ten-id-yawin war ma yenger kra: **`ruaḥ`** · **`ḥesed`** ·
**`ṣedeq`** · **`Tora`** · **`Cabbat`** · **`Mickan`** · **`minḥa`** · **`Ceol`** ·
**`Maciaḥ`** · **`navi`**. Taɛbranit tella ɣer tama n yal yiwen, ihi tettwaliḍ ayen
yeqqimen.

Ismawen n yimdanen d yimukan ttwarun s timesliwin n taɛbranit: **Avraham**, **Moce**,
**David**, **Yisrael**, **Miṣrayim**, **Yerucalayim**.

Icaya 53:5 (`isaiah/53/5`):

> Maca netta yettwajerḥen imi n iḥricen-nneɣ, yettwaḥeccem imi n yir tiḥrici-nneɣ;
> aḥkam n talwit-nneɣ yella-d ɣef-s, d s tuḥda-s i neḥla.
